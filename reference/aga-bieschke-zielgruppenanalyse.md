## Der Ablauf (4 Schritte)

### Schritt 1 — Nische qualifizieren
Prüf-Fragen (möglichst alle „JA"):
- Löst du ein echtes, starkes Problem / erfüllst einen starken Wunsch?
- Megamarkt? (Geld · Körper · Beziehungen · Hobbys/Tiere · Persönlichkeitsentwicklung)
- Gibt es schon eine Community / Mitbewerber zum Thema?
- **Hast du das Thema gegoogelt** → gibt es schon Kurse dazu? (= Nachfrage-Beweis)
- Hashtag auf Instagram gesucht → Profile mit mehreren Tausend aktiven Followern?
- Erfolgreiche Kurse auf udemy.com (auch auf Englisch suchen)?
- Kann sich die Zielgruppe einen Kurs/Coaching leisten?
- Wird das Thema aktiv in Social Media diskutiert?
- Hast du eine eigene Lösung / einen speziellen Ansatz?
- Magst du das Thema? Ist es Evergreen?

### Schritt 2 — Titel erstellen (Produktsprache!)
**Formel:** GROSS geschriebener Titel + Untertitel als Wertversprechen. **Konkrete Zahl / Datenpunkt / Zeitrahmen** einbauen. Messbares, sehr klares Ergebnis. Timeline wenn möglich.
Beispiele aus ihrem Kurs (nur als Struktur-Inspiration): „SLEEPING BABY: Wie dein Kind innerhalb von 14 Tagen durchschläft – ohne komische Trainingsmethoden" · „KARRIERE TROTZ ADHS – In 6 Wochen zu Struktur, Fokus & beruflichem Erfolg". → Muster: **NAME + Ergebnis + Zeitrahmen + „ohne [gefürchteter Weg]"**.

### Schritt 3 — DAS RECHERCHE-DOKUMENT (Herzstück)
4 Abschnitte, aber **erarbeitet in dieser Reihenfolge** (Fakten zuerst, Überblick zuletzt):

1. **Studien, Artikel & Quellen** — so viele Statistiken/Datenpunkte wie möglich zum Schmerzpunkt. Pro Quelle: *Was wurde untersucht? · Was herausgefunden? · Warum relevant? · URL*. Keine erfundenen Zahlen → Glaubwürdigkeit für Hooks/Ads.
2. **Kundengefühle & emotionale Trigger** (= **Contentsprache!**) — tiefe Liste der Schmerzpunkte, Probleme, heimlichen Sehnsüchte. Leitfragen: *Was machen sie im Alltag? Wovon träumen sie heimlich? Wie versuchen sie den Schmerz aktuell zu lösen?* **Tagebuch-Test:** „Stell dir vor, sie schreibt abends allein in ihr Tagebuch — was steht da drin?" → liefert die wortwörtliche Kundensprache für Salespage, Kurs-Texte, Content.
3. **Marketing-Angles & Hooks** — aus 1+2 so viele Angles/Hook-Ideen wie möglich. Einige mit harten Fakten/Statistiken (glaubwürdiger). Für Instagram: **emotional, schnell verständlich, visuell vorstellbar.**
4. **Überblick** (zuletzt) — Kurz-Zusammenfassung: *Was ergab die Recherche? · Wer ist der Kunden-Avatar (inkl. Trigger)? · Beste Marketing-Angles?* = roter Faden für Salespage, Ads, Content.

### Schritt 3b — Kursstruktur
Module + Lektionen als **Transformationsreise**. Pro Lektion: 1. Titel · 2. Beschreibung · 3. „Nach dieser Lektion weiß/kann der Kunde…" (kleines Etappen-Transformationsziel) · 4. Materialien-Marker `[WORKSHEET: …]` / `[VISUAL: …]`. Kein Blabla, jeder Schritt spürbarer Mehrwert.
**Wichtig (Julia-kompatibel):** Kurs erst mit Zukunfts-Datum **vorverkaufen/validieren**, bevor man ihn ganz produziert.

### Schritt 4 — Problemlösungs-Webinar
Das kostenlose Webinar muss (8 Pflicht-Elemente):
1. ein **ganz spezifisches** Problem lösen · 2. Resultate/Mindset-Shift/Gefühl erzeugen, *bevor* jemand zahlt · 3. so gut sein, dass man Geld hätte nehmen können · 4. eine Abkürzung liefern · 5. leicht konsumierbar · 6. dich als Expertin zeigen · 7. **grossen Leerraum zum Produkt** offen lassen · 8. Avatar erfüllt Mindestanforderung (Problembewusstsein).
Ablauf: Einleitung → Aufwärmen/Interaktion → Überleitung → Schmerzen & Probleme nennen → Agenda → Vorstellung → Filtern → **Contentphase (20–40 Min, inkl. Glaubenssätze/Einwände ausräumen + Sales-Framing)** → **Pitchphase (5–10 Min)**.

## Wie das zu Patricias Welt passt

- **Ergänzt Julia Trost & Hormozi, ersetzt sie nicht.** aga = *Zielgruppen-Recherche + Webinar-Trichter*. Julia = Produkttreppe/Story/Launch. Hormozi = Copy-Layer. Alle drei greifen ineinander.
- **Contentsprache vs. Produktsprache** (Patricias Lieblings-Take-away):
  - *Contentsprache* = Abschnitt 2 (Kundengefühle, Tagebuch-Wortlaut) → so klingen **Hooks & Captions**: symptombewusst, in ihren Worten. Deckt sich mit [[feedback_hooks-symptombewusst-nicht-produktbewusst]].
  - *Produktsprache* = Titel + Überblick → so klingt das **Angebot/die Salespage**: konkretes Ergebnis + Zeitrahmen + „ohne".
- **Compliance:** Für doTERRA gilt trotzdem: keine Heilversprechen, keine erfundenen Zahlen ausserhalb belegter Quellen. Statistiken im Recherche-Dokument immer mit URL + Interessenlage kennzeichnen (macht Patricia im IG-Kundenmaschine-Doc schon vorbildlich).

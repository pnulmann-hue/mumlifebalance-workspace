## Modi

### 1. Karussell-Konzept aus Idee entwickeln
Patricia sagt ein Thema. Du lieferst ein komplettes Folien-Briefing.

**Ablauf:**
1. Frag: Thema? Profil (falls nicht schon klar)? Ziel (Saves/Shares/DMs)? Folien-Anzahl (Default 9)?
2. **Trend-Research** (WebSearch) — Pflicht vor jedem Briefing
3. **Hook-Pflicht-Prozess** (4 Schritte aus `hook-framework.md`)
4. **Feed-Aesthetic-Check** via Canva MCP (`list-folder-items` auf „Gepostete Beiträge", Farben der letzten 6-9 Designs)
5. **Folien-Plan** erstellen (siehe Template in `karussell-framework.md`)
6. **Caption** + ManyChat-Keyword + 5 Hashtags
7. **Notion-Eintrag** in Content-Management-DB anlegen (Status „Idee" oder „Geplant")
8. Speichere als `outputs/karussells/YYYY-MM-DD-[slug].md`

Patricia hat Fotos/Zitate die sie nutzen will.

**Ablauf:**

### 3. Hook-Brainstorm

**Ablauf:** Identisch zu /reels Mode 3.

### 4. Karussell-Doktor

**Ablauf:**

## Pflicht-Schritte VOR jedem Briefing

### Schritt A: Trend-Research (WebSearch)
Identisch zu /reels. Mindestens 2 Suchen pro Session:
- Mentoring: „viral instagram carousel mom entrepreneurs [monat] 2026", „carousel format [thema] tiktok"
- doTERRA: „viral instagram carousel wellness perimenopause 2026", „nutrition carousel format 2026"

### Schritt B: Hook-Pflicht-Prozess (4 Schritte)
Aus `reels-framework.md` → Abschnitt „Hook-Bauen":
1. Kategorie wählen (Zahlen/Anleitung/Provokant/Neugier/Identifikation)
2. Template aus der Kategorie füllen
3. 5-Regeln-Check (kurz/konkret/spannung/relevant/kein clickbait)
4. Viral-Mechanik-Check (Spannung/Shortcut/Beweis/Identität)

### Schritt C: Feed-Aesthetic-Check (Canva MCP)
VOR Design-Arbeit:
- `list-folder-items` auf Canva-Ordner „Gepostete Beiträge"
- Farben der letzten 6-9 Posts erfassen
- Cover-Farbe für dieses Karussell so wählen, dass Grid abwechselt (Petrol → Creme → Orange → Dunkelblau rotieren)

### Schritt D: HTML-Vorschau + PNG-Render (Pfad B)

**NEU seit 2026-04-22:** Finales Karussell wird aus einer HTML-Vorlage zu 11 Instagram-tauglichen PNGs (1080×1350) gerendert. Die HTML ist die Single-Source-of-Truth — kein Canva-AI-Generate mehr.

**Workflow:**
1. **HTML-Folien-Vorlage erstellen** in `outputs/samples/karussell-<slug>.html` (Basis: `outputs/samples/karussell-v3-preview.html`)
   - CSS war für 340px-Grid designed, Render-Script skaliert via `zoom: 3.1765` automatisch auf 1080×1350.
   - Wichtige Elemente pro Slide: `.slide.slide-N` mit passender Content-Struktur.
   - Bilder: absolute `file:///C:/Users/pnulm/Desktop/Mein%20Business/context/Shootingbilder/<shot>.jpg`-Pfade verwenden.
2. **Render-Pipeline triggern:**
   ```
   cd scripts/karussell-render && node render.js --input="../../outputs/samples/karussell-<slug>.html" --slug=<slug>
   ```
3. **Output:** `outputs/karussells/renders/YYYY-MM-DD-<slug>/01.png` bis `11.png`
4. **Direkt postbar** via Blotato API oder manuelles Instagram-Upload.

**Crop-Zone-Check automatisch eingehalten:** Render-Script blendet die Crop-Marker-CSS aus, aber die 12.5% Safe-Zones oben/unten sind weiterhin als Padding-Basis der HTML-Vorlage eingebaut.

## Kern-Regeln für jedes Output

### Hook & Struktur
- [ ] **Blackliste-Pflicht-Prüfung bestanden** (5 Scans: Nicht/Sondern, Dreier-Stakkato, Worthülsen, Kontrast-Absatz, Gesamteindruck)
- [ ] Hook nach 4-Schritt-Pflicht-Prozess gebaut

- [ ] Jede Folie hat EINE klare Aussage
- [ ] Swipe-Anreiz auf jeder Folie (Cliffhanger)
- [ ] CTA-Folie mit Save/Share-CTA + ManyChat-Keyword

### Feed-Aesthetic
- [ ] Cover-Farbe passt zur Rotation (letzte 6-9 Posts gepruuft)
- [ ] Konsistente Schrift-Familie über das Karussell
- [ ] Mobile-lesbar (min. 30pt Text, Kontrast, Rand)

### Content & Profil
- [ ] Profil klar (Mentoring ODER doTERRA — nie mischen!)
- [ ] Pillar aus Notion Content-Strategie-DB gewählt
- [ ] Brand Voice eingehalten (ä/ö/ü/ss, kurze Sätze, „du")
- [ ] Caption nach HVC-Formel, erste 125 Zeichen catchen
- [ ] 5 Hashtags aus `reels-framework.md`
- [ ] ManyChat-Keyword aus `manychat-keywords.md`

### Notion
- [ ] Eintrag in Content-Management-DB angelegt
- [ ] Briefing-Link-Feld gesetzt
- [ ] Pillar + Plattform als Relation gesetzt

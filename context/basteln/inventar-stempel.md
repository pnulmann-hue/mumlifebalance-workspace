# Stempel-Register — das ID-System

**Angelegt:** 2026-08-18 · **Das ist das Herzstück.** Hier steht, was du hast, wo es liegt und wofür es taugt.

---

## Die Grundidee: Nummer statt Thema

**Das Problem mit thematischer Ablage** („alle Weihnachtsstempel in eine Box"): Ein Set wie „Alles Gute!" passt zu Geburtstag, Prüfung, Umzug und Weihnachten. Du müsstest es vierteilen oder dich jedes Mal neu entscheiden. Und bei jeder neuen Erkenntnis umsortieren.

**Die Lösung:** Du legst physisch nach **fortlaufender Nummer** ab — stur, ohne Nachdenken. Die thematische Suche mache ich. Wie in einer Bibliothek: die Signatur sagt nicht, worum es geht, sie sagt nur, wo es steht.

Heisst konkret:
> Du: „Ich will Weihnachtskarten basteln."
> Ich: „Nimm **1017** und **1023** (Clearstamps) und **3042** (Stanze). Dazu Digipapier `Papiere Vintage Weihnachten`. Hier drei Ideen.“
> Du: greifst dreimal zu, fertig. Kein Suchen, kein Kistenwühlen.

**Ein Set kann bei mir in zehn Themen auftauchen — es liegt trotzdem nur an einer Stelle.**

## Das Nummern-Schema: Typ-Block + laufende Nummer

Vierstellig, nur Zahlen — **die erste Stelle sagt, um welche Sorte Material es sich handelt.** Damit hat jede Kiste ihren eigenen, lückenlosen Nummernkreis, und du schreibst trotzdem nur Ziffern.

| Block | Material | Kiste |
|---|---|---|
| **1000–1999** | Clearstamps | Clearstamp-Kisten |
| **2000–2999** | Holz-/Gummistempel | |
| **3000–3999** | Stanzen | Magnetbox / Mappe |
| **4000–4999** | Schablonen / Stencils | flach |
| **5000–5999** | Embossing-Folder | |
| **6000–6999** | Punchboards & Werkzeuge | |
| **7000–7999** | Farben & Stempelkissen | Farbkasten |
| 8000–9999 | frei — für Sorten, die noch dazukommen | |

**Beim Anschauen sofort klar:** `3042` ist eine Stanze. `1017` ein Clearstamp. Kein Nachschlagen, keine Buchstaben.

## Bündel à 10 — so findest du in Sekunden

Genau wie du es vorhast: **immer 10 Stück mit einem Gummi zusammen**, dazu ein Beschriftungs-Kärtchen.

```
[ 1001 – 1010 ]   ← Kärtchen oben aufs Bündel, mit Gummi fixiert
[ 1011 – 1020 ]
[ 1021 – 1030 ]
```

Weil jeder Typ seinen eigenen Block hat, sind die Bündel **lückenlos** — `1001–1010` enthält genau zehn Clearstamps, keine Sprungstellen.

**Wenn ich dir `1017` nenne:** du greifst das Bündel `1011–1020`, ziehst den Gummi ab, nimmst die siebte Hülle. Kein Durchblättern der ganzen Kiste.

**Praktische Regeln:**
- **Nicht vorsortieren.** Nummerier einfach in der Reihenfolge, wie du die Sets in die Hand nimmst. Das Thema spielt keine Rolle — die Suche mache ich.
- **Angebrochenes Bündel bleibt offen**, bis 10 zusammen sind. Zwischenstand ist kein Problem.
- **Nie neu vergeben:** Sortierst du ein Set aus, bleibt die Nummer verbrannt und das Bündel hat neun. Sonst zeigt ein altes Foto irgendwann aufs falsche Material.
- **Block voll?** Unrealistisch (1000 Plätze pro Sorte), aber falls doch: nächsten freien Block übernehmen und hier notieren.

**Meine Antwortform** — immer Nummer plus Sorte, damit du die richtige Kiste ziehst:
> "Nimm **1017** (Clearstamp) und **3042** (Stanze). Dazu Digipapier X aus Ordner Y."

## Der Erfassungs-Workflow (du musst nicht auf mich warten)

1. **Nummerieren** — nächste freie Nummer nehmen, aufs Set schreiben oder Etikett drauf
2. **Fotografieren** — Set mit **sichtbarer Nummer** im Bild
3. **Ablegen** — in Nummernfolge, fertig
4. **Schicken** — Foto an mich, ich trage alles unten ein

Der Punkt an dieser Reihenfolge: **du kannst 20 Sets in einem Rutsch durchnummerieren und ablegen**, ohne dass ich dazwischen etwas tun muss. Die Fotos schickst du, wann es passt. Nichts blockiert.

**Etiketten:** Du hast einen Plotter — plotte oder drucke dir einen Bogen kleiner Nummern-Etiketten (z.B. `1001` bis `1100` für die Clearstamps, dazu die Bündel-Kärtchen `1001–1010` usw.) auf Klebefolie. Einmal machen, dann nur noch aufkleben. Sag Bescheid, wenn ich dir eine Vorlage dafür bauen soll.

## Wie ein Set erfasst wird — zwei Ebenen

**Ebene 1: die Nummer = das Set.** Eine Nummer pro physischer Einheit (= was in einer Hülle liegt). Keine Unternummern für Einzelstempel — wenn eine Folie neu geordnet wird, wären sie falsch.

**Ebene 2: der Inhalt = einzeln aufgelistet.** Jeder Spruch im Klartext, jedes Motiv als kurze Beschreibung. **Darauf suche ich.** Ohne diese Liste kann ich nur ‚irgendwas mit Geburtstag‘ sagen statt den passenden Stempel benennen.

Pflichtfelder pro Eintrag:

```
### 1001 — "Set-Name"
- **Typ:** Clearstamp-Set / Stanze / Schablone …
- **Format:** A6, 7 Stempel  (bzw. Grosse bei Stanzen)
- **Hersteller / Artikel-Nr. / Lagernr.:** falls bekannt
- **Inhalt:** Spruch 1 · Spruch 2 · …   (vollstaendig!)
- **Tags:** aus dem Vokabular unten
```

**Verweis-Form in meinen Antworten:** Nummer bringt sie zur Hülle, Klartext zum Stempel darin.
> "**1001** (Clearstamp) — daraus die Stempel *Nachträglich* und *Alles Liebe zum Geburtstag!*"

**Gemischte Sets: pro Spruch taggen, nicht pro Set.** Wenn ein Set vier Weihnachtssprüche und zwei allgemeine enthält, würde ein Set-Tag `weihnachten` sie zu sechs Stempeln führen, von denen nur vier passen. Dann so:

```
- **Inhalt & Tags:**
  - Frohe Weihnachten — `weihnachten`
  - Alles Gute — `allgemein` `geburtstag`
```

## 🎄 Beispiel: „Ich will Weihnachtskarten basteln"

So sieht meine Antwort aus — **heute schon**, allein aus dem digitalen Bestand. Physische Stempel kommen dazu, sobald erfasst.

**Motive & Sprüche** (`Plotter/Digistamps, Bilder, etc/`)
- `Coole Weihnachten` — 158 Dateien, moderner Stil
- `Elemente Weihnachtszauber` — 89, klassisch
- `Vintage Weihnachten` — 52, nostalgisch
- `Sprüche Weihnachten` — Textbausteine

**Papier** (`Plotter/Papier/`)
- `Papiere Vintage Weihnachten` — 46 · `Papier Vintage Weihnachten basic` — 41
- neutral dazu: `Basics` (42), `Punkte & Streifen` (34)

**Kartenbasis** (`Plotter/Karten/`)
- `Kartenrohlinge` (42) + `Kartenrohlinge2` (33) — Grundformen
- `Weihnachten` (3) · `Weihnachtsstern für Karte` (2) — fertige Weihnachtskarten
- `Karten-und-Boxen-1` / `-2` — Karte plus passende Box im Set

**Wenn's auch verpackt sein soll** (`Plotter/Verpackungen/`)
- `Weihnachtsbaum` (16) · `Sternenboxen` (10) · `Schneeflockenbox` (3)
- Anhänger: `AnhängerWeihnachten` (6)

**Couverts:** Envelope Punchboard, Grösse frei — passend zu jedem Rohling

**Drei Ideen aus deinem Material:**
1. **Vintage-Serie in Batch** — ein Digipapier aus `Vintage Weihnachten` als Panel, Motiv aus `Coole Weihnachten` mit Copic koloriert, Spruch drauf. Zehnmal dasselbe Layout, unterschiedliche Motive — sieht nach Serie aus, geht doppelt so schnell.
2. **Karte + Box im Set** — aus `Karten-und-Boxen-1`: Karte und Verpackung im gleichen Papier. Für die Geschenke, bei denen die Karte sonst verloren geht.
3. **Sternenbox mit Inhalt** — `Sternenboxen` + Handcreme oder Guetzli, Anhänger aus `AnhängerWeihnachten`. Das Mitbringsel, das du im Dezember zehnmal brauchst.

**⏰ Timing-Hinweis:** Für Adventskalender und Weihnachtspost ist **Ende Oktober** die richtige Batch-Zeit. Im Dezember bastelt niemand entspannt.

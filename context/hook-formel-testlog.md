# Hook-Formel-Turnier — Test-Log

**Zweck:** Systematisch alle Hook-Formeln testen, um eine datenbasierte Rangliste für Patricias Zielgruppe zu bekommen. Methode: pro Test 1 emotionales Mama-Thema + 1 candid Video + 1 Caption, **nur die 3 Hooks variieren** (3 verschiedene Formeln). Innerhalb einer Runde sind die Formeln sauber vergleichbar; über mehrere Runden zeigt sich, welche Formeln immer wieder gewinnen.

**Konstanten (aus Daten):** emotionales Mama-Lebens-Thema (grüne Liste `mama-schmerz-themen-pool.md`) + candid Home-Video beim Tun + Hook ab Sek 0 + unter 20 Sek + Reels über Tage verteilt.

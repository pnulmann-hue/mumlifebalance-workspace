# 📚 doTERRA E-Book-Bibliothek

**Hier kommen Patricias Fach-Bücher rein** (EPUB, PDF, DOCX, MOBI), damit der Companion + die Content-Skills darauf zugreifen können.

Dieser Ordner ist **bewusst von der `.gitignore` freigeschaltet** (Ausnahme von der globalen `*.epub`/`*.pdf`-Sperre) — anders als der große persönliche Ordner `context/doTERRA/` (groß geschrieben), der Videos/Kurse enthält und aus Repo-Größengründen ausgeschlossen bleibt.

## ⚠️ Wichtig: Schreibweise

Bücher **immer hier** ablegen: `context/doterra/ebooks/` — **klein geschrieben**.
(Nicht in `context/doTERRA/Ebooks/` mit großem D — der Ordner ist gesperrt.)

## So fügst du ein neues Buch hinzu

**Option A — direkt über GitHub (am einfachsten, kein lokales Git nötig):**
1. Repo auf github.com öffnen → in diesen Ordner navigieren (`context/doterra/ebooks/`)
2. „Add file" → „Upload files" → EPUB/PDF reinziehen → „Commit changes"
3. In der nächsten Claude-Session: „Lies das neue Buch in ebooks/ ein"

**Option B — lokal (wenn du einen Git-Klon hast):**
1. Buch in `context/doterra/ebooks/` kopieren
2. `git add context/doterra/ebooks/ && git commit -m "Buch X" && git push`

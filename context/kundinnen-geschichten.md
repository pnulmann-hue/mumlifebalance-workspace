# Kundinnen-Geschichten — echte Fälle für Säule 2

> **Wozu:** Die Geschichte einer ganz normalen Kundin wirkt stärker als die eigene, weil die
> Leserin denkt „die ist wie ich, und die hat es geschafft“. Das ist Inspiration und
> Verkaufsbeweis in einem (Podcast-Notiz [[podcast-2026-09-29-vom-ego-zum-kunden]]).
> Bis 30.09.2026 gab es im Workspace **keinen einzigen** dokumentierten Fall, und weil
> nichts erfunden werden darf, konnten die Content-Skills das stärkste Format nie bauen.

## 🚨 Regeln

1. **Nur was Patricia erzählt hat.** Keine Zahl, keine Szene und kein Zitat dazuerfinden.
   Was fehlt, bleibt als „offen“ stehen.
2. **Zitat ≠ Zusammenfassung.** Ein Zitat steht nur in Anführungszeichen, wenn es der
   Wortlaut der Kundin ist (abgetippt aus Sprachnachricht oder Screenshot). Patricias
   Nacherzählung ist eine Zusammenfassung und wird auch so gekennzeichnet.
3. **Keine Klarnamen in dieser Datei.** Das Repo ist öffentlich. Fälle heissen hier
   „Kundin A, B, …“. Wer es ist, steht nur in `context/persoenlich/kundinnen-namen.md`
   (gitignored).
4. **Freigabe vor Verwendung.** Solange `Freigabe` auf *offen* steht, darf der Fall
   nur **anonym und ohne erkennbare Details** in einen Beitrag. Mit Namen oder Screenshot
   erst nach einem Ja der Kundin.
5. **Die drei Teile sammeln:** Vorher (in ihren Worten) · was sie gemacht hat · Nachher.
   Das **„wie es sein könnte“** schreibt dann der Beitrag, und zwar für die Leserin.

## So kommt ein Fall hier rein

Patricia bekommt das meiste als **Sprachnachricht**. Der einfachste Weg:

- **Im Chat erzählen**, ein paar Sätze reichen („gestern hat mir … geschrieben“). Claude
  trägt den Fall ein und fragt nur nach, was für einen Beitrag fehlt.
- **Die Sprachnachricht der Kundin** als Datei in `video/input/` oder ins Handy-Album
  `DCIM/Content-Inbox` legen. Dann transkribiert Claude sie lokal (faster-whisper), und
  der Wortlaut steht als echtes Zitat drin.
- **Screenshot** eines Chats in die Content-Inbox legen. Das ist sofort Wortlaut.

## Vorlage (je Fall kopieren)

```markdown
### Kundin X · <Angebot> · <Datum der Rückmeldung>

| | |
|---|---|
| **Angebot** | welcher Kurs, welches Freebie |
| **Vorher** | ihre Lage in ihren Worten — oder „offen“ |
| **Was sie gemacht hat** | der konkrete Schritt |
| **Nachher** | was sich verändert hat, mit Zeitangabe wenn bekannt |
| **Wortlaut** | nur echte Zitate, sonst „offen“ |
| **Quelle** | Sprachnachricht / Screenshot / Call · wo abgelegt |
| **Freigabe** | offen · anonym ok · mit Vorname ok · mit Namen + Bild ok |
| **Passt zu** | Angebot oder Launch, für den der Fall Beweis ist |
| **Schon verwendet** | Datum + Beitrag |
```

### Kundin A · Instagram-Kundenmaschine (ehemalige Kundin) · 29.09.2026

| | |
|---|---|
| **Angebot** | Instagram-Kundenmaschine (früher gekauft). Der neue Schritt kam aber über Patricias **Claude-Anleitung**, nicht über einen Kurs |
| **Vorher** | Sie hatte mit ChatGPT gearbeitet und Patricia davon geschrieben. *Was genau sie gemacht hat und was sie daran gestört hat: offen* |
| **Was sie gemacht hat** | Patricia hat ihr per Sprachmemo geschildert, was sie mit Claude alles macht. Die Kundin hat Claude danach **mit Patricias Anleitung selbst installiert** |
| **Nachher** | Laut ihrer Sprachnachricht war sie „krass schnell“ mit ihrem Zeug fertig und hat jetzt „tausend Ideen“, die sie noch umsetzen könnte. **Absolut begeistert.** *(Patricias Zusammenfassung, nicht der Wortlaut)* |
| **Wortlaut** | offen. Die Sprachnachricht liegt auf dem Handy; abgetippt wäre sie ein echtes Zitat |
| **Quelle** | Sprachnachrichten, 29.09.2026 |
| **Freigabe** | offen |
| **Passt zu** | **KI-Launch Oktober** (Masterclass Do 8.10., KI-Kurs Claude Code): Beweis, dass eine Networkerin ohne Technik-Hintergrund es mit einer Anleitung selbst einrichtet. Dazu das Motiv „Da geht so viel mehr“ und der Wechsel von „KI wie Google“ zu „KI, die mitarbeitet“ |
| **Schon verwendet** | — |

**Für einen Beitrag fehlt noch:** was sie „fertig“ gemacht hat (Captions? Freebie? Salespage?) · wie lange es vorher gedauert hat · ob sie technisch eher unsicher ist · Freigabe.

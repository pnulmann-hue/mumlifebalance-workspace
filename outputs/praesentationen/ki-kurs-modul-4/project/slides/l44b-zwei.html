Lektion 4.4b

Zwei Wörter, die sich ähnlich anhören

Git

Ein kleines Programm auf deinem Rechner.

Es schreibt mit, was sich ändert.

Auf dem Mac meistens schon da,

unter Windows einmal installieren.

GitHub

Der Ort im Netz, wo es dann liegt.

Braucht ein Konto, kostenlos.

Du siehst dort deine Dateien

und wer wann was geändert hat.

Diese Verwechslung kostet in jedem Anfängerkurs eine halbe Stunde. Sag den Satz einmal ganz langsam: Git ist das Programm, GitHub ist der Ort. Wenn später die Meldung kommt „Git ist erforderlich“, wissen sie dann, was gemeint ist.

Lektion 4.4b

Du machst es nicht selbst

Du musst weder Git installieren noch wissen, was ein Repository ist. Du sagst einfach, was du willst:

„Ich will meinen Arbeitsplatz bei GitHub sichern. Ich habe noch nie damit gearbeitet. Führ mich Schritt für Schritt durch, und sag mir bei jedem Schritt, was ich anklicken muss.“

Sie prüft, was auf deinem Rechner fehlt, schickt dich für das Konto einmal auf die Webseite und macht den Rest selbst.

Zeig das live und lass die Antwort wirklich stehen, auch wenn es ein paar Schritte sind. Genau hier sehen sie zum ersten Mal, dass sie Technik nicht lernen müssen, sondern beschreiben.

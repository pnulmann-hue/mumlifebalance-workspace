# 🗂️ Notizen — Index

Patricias Gedankenstützen-Sammlung. Zentrale Inbox für spontane Ideen + thematische Notiz-Dateien.

## Dateien

- [[notiz-inbox]] — laufende Inbox für alles, was spontan reinkommt

## So nutzt du das

- **Schnell erfassen:** im Chat *"Notiz: …"* oder `/notiz <text>`
- **Abrufen:** `/notiz` (ohne Text) oder *"zeig mir meine Notizen"*
- **Thematisch bündeln:** wird eine Inbox-Notiz grösser, legt Claude eine eigene Datei
  `outputs/notizen/YYYY-MM-DD-<thema>.md` an und verlinkt sie hier.

# 📥 Notiz-Inbox — Patricias Gedankenstütze

> Hier landet alles, was dir zwischendurch in den Sinn kommt. Erfasse es einfach im Chat mit
> Claude ("Notiz: …" oder `/notiz`), und es wird hier chronologisch abgelegt.
> **Am Laptop:** neue Session öffnen → `/notiz` (oder "lies meine Notizen") → alles ist wieder da.

**Wie das funktioniert:**
- **Erfassen:** Sag im Chat *"Notiz: <dein Gedanke>"* oder tippe `/notiz <text>`. Claude hängt den Eintrag unten mit Datum an.
- **Abrufen:** Sag *"Zeig mir meine Notizen"* oder tippe `/notiz` ohne Text. Claude liest diese Datei vor.
- **Erledigt / archivieren:** Sag *"Notiz X erledigt"* → Claude hakt sie ab oder verschiebt sie ins Archiv unten.

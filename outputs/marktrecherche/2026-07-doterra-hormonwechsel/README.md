3. **Hooks** — aus der Hook-Bibliothek Formeln wählen und anpassen, strikt P→I→E abwechselnd. → `03-hooks-und-captions.md`
4. **Captions** — pro Hook eine Caption in der eigenen Stimme (Zeitanker → Zahl → Body → 1 CTA → max 5 Hashtags). → `03-hooks-und-captions.md`

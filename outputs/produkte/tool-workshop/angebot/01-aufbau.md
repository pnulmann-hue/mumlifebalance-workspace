# 01 · Aufbau Tool-Workshop

Werte aus `00-bauplan.md`. Live 10. und 11.11.2026, danach drei Tage Begleitung, Aufzeichnung in ThriveCart Learn.

## Vorbereitung (Mail 0 und Lektion „Bevor es losgeht“)

- [ ] Claude-Konto anlegen auf claude.ai (die Gratis-Version reicht zum Start)
- [ ] Netlify-Konto anlegen auf netlify.com (gratis), nur nötig, wenn die Seite ein AC-Formular tragen soll
- [ ] Nischengenerator ausfüllen und den Satz der ersten Nische notieren
- [ ] Eine Frage aufschreiben, die dir die Leute in deinem Network immer wieder stellen
- [ ] Dein Wissen fürs Tool: Hast du ein Workbook, E-Book oder PDF, bring es mit. Wenn nicht, schreib in ein paar Sätzen auf, was dein Tool können soll. Das reicht.

**Warum das Wissen beim Bauen hinein muss:** Ein einfaches Tool fragt später keine KI mehr. Alles, was es sagt, schreibt Claude beim Bauen in die Datei. Wer ein Workbook mitbringt, lädt es per Büroklammer in den Chat („Bau die Ergebnisse aus dem Wissen in diesem Dokument“). Wer nichts hat, beschreibt, was das Tool können soll, und Claude füllt den Rest mit allgemeinem Wissen. Dann gilt: jedes Ergebnis selbst ausfüllen, lesen und im Chat nachschärfen, bis es klingt wie sie und stimmt. Das Wissen ist danach eingefroren: Änderung im Chat, neue Datei auf Netlify. Keine Heilversprechen in Ergebnistexten, auch wenn sie im Firmenmaterial stehen.

## Tag 1 · Di 10.11. · Dein Tool (live, 19:00 Uhr, rund 90 Minuten)

| Teil | Inhalt | Ergebnis |
|---|---|---|
| 1 | Warum ein Tool statt PDF: Fast alle im Network verschenken PDFs. Ein Tool gibt der Zielgruppe ein Erlebnis und ein Ergebnis zu ihrem Problem, öffnet den Kontakt und macht das eigene Produkt zum natürlichen nächsten Schritt | Klarheit, was gebaut wird |
| 2 | Von der Nische zur Tool-Idee: Welche Frage beantwortet dein Tool? Formate: Test · Check · Rechner · Planer · Generator | eine Tool-Idee in einem Satz |
| 3 | Live bauen im Claude-Chat: Auftrag schreiben, Fragen festlegen, Auswertung nach Regeln, Ergebnis mit nächstem Schritt | ein laufendes Artifact |
| 4 | Feinschliff: Farben, Texte in deiner Stimme, Knopf am Schluss | fertiges Tool |
| 5 | Teilen: Artifact veröffentlichen, Link testen am Handy | Link, der funktioniert |

**Grenzen, die gesagt werden müssen:** Das Tool rechnet nach Regeln, ohne eigene KI-Antworten. Ein Tool, das selbst KI-Texte schreibt, braucht einen Server und einen API-Schlüssel, das ist nicht Teil des Workshops. Ein Formular direkt im Artifact geht nicht, ein Link dagegen schon.

**Hausaufgabe bis Tag 2:** Tool drei Personen schicken und fragen, ob das Ergebnis stimmt.

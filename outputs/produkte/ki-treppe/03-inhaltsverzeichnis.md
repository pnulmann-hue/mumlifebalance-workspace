## Teil A — Was Julia wirklich macht

Kompletter Durchgang durch „Claude Code Mastery", 57 Lektionen, 9 Kapitel.

### 🚨 Der wichtigste Befund: Sie gibt nicht alle Skills weiter

Modul 2.1 endet mit **„Bonus: 3 meiner besten Skills für dich"**. Drei. Nicht dreissig.
Der Rest des Moduls unterrichtet, wie man selbst welche baut:

> Der Vorteil von Skills · So sind Skills aufgebaut · So erstellst du eigene Skills —
> mit dem Skill Creator Skill · Skills manuell erstellen — ohne den Skill Creator ·
> Skills in die App laden · Achtung vor Skills aus dem Internet · Bonus: 3 meiner
> besten Skills für dich

**Das ist näher an Patricias erstem Satz** („wie man Skills erstellt, aber nicht was
reinkommt") als an „alles rein". Die Annahme, Julia gebe ihr ganzes Arsenal mit, hält
dem Blick in den Kurs nicht stand.

### Kapitel 6 ist Werkzeug, nicht Strategie — die offene Frage ist beantwortet

> So automatisierst du die Erstellung und das Posten deiner Karussell Beiträge · So
> recyclest du deinen gesamten Content · **Fehlermanagement: Gute Karussell Beiträge** ·
> Reels erstellen mit Claude Code · YouTube Videos hochladen · Active Campaign
> Verknüpfung · Für Pinterest Posts erstellen & hochladen · Digitale Produkte über Etsy
> verkaufen · Claude Code und Amazon KDP

Null Content-Strategie. Reiner Maschinenraum. **Das bestätigt die Maschine-gegen-
Treibstoff-Trennung** aus [[02-kurs-konzept]] — sie macht es genauso, nur ohne es zu
benennen.

Bemerkenswert ist die eine Lektion **„Fehlermanagement: Gute Karussell Beiträge"**. Die
braucht sie, weil automatisch erzeugte Karussells schlecht werden. Genau dafür hat
Patricia einen ganzen Apparat: Beitrags-Check, Blackliste, der letzte Check, das
Prüfskript. Bei Julia ist es eine Lektion, bei Patricia kann es ein halbes Kapitel sein.

### Sieben Lücken — das ist Patricias Kurs

| Was bei ihr fehlt | Was Patricia dazu hat |
|---|---|
| **Kein Chat, kein Cowork.** Lektion eins heisst „Der Umzug von ChatGPT nach Claude", dann direkt Setup Claude Code | Der Weg über drei Stufen mit „auf jeder Stufe ein Gewinn". Ihre Zielgruppe ist technisch ängstlicher |
| **Kein Wissensfundament.** Sie hat Prompt-Handwerk („Wie du mit Claude redest", „3 Regeln"), aber nichts darüber, wie das eigene Wissen dauerhaft hineinkommt | Der **Business-Brief** samt Buch-Technik. Das ist Patricias stärkstes eigenes Material |
| **Keine Freigabe-Schicht.** Agenten und Auto-Posting, aber nichts dazwischen | Das **Cockpit mit dem Freigabe-Knopf**. Eine Network-Mama kann nicht ungeprüft posten — ihr Konto hängt an einem Partnerunternehmen |
| **Qualitätssicherung: eine Lektion** | Beitrags-Check, Blackliste, Hook-Check, `texte-pruefen.py`, Visual-QA. Belegt mit echten Fehlern |
| **Sicherheit nur gegen fremde Skills** | Die Aufräumaktion vom 13.09. — Schlüssel und 32 Kundendatensätze offen im öffentlichen Repo. Eine echte Geschichte, die niemand sonst erzählen kann |
| **Kein Network Marketing, keine Mama-Realität** | Die ganze Positionierung |
| **Breite statt Tiefe** — Etsy, Amazon KDP, Pinterest | Patricias Zielgruppe braucht kein Etsy. Sie braucht Instagram, Mails und ein Produkt |

### Was ich von ihr übernehmen würde

- **Kapitel 1 als reine Orientierung**, bevor irgendetwas passiert: Roadmap,
  Begriffe-Cheatsheet, Checkliste. Bei Patricias Zielgruppe noch wichtiger.
- **Zusammenfassung und Checkliste am Ende jedes Kapitels.** Konsequent bei allen neun.
- **„Welcher Plan ist der Beste"** als eigene Lektion. Die Abo-Frage kommt sowieso,
  und offen beantwortet nimmt sie die Bremse raus.
- **„Achtung vor Skills aus dem Internet."** Guter Punkt, gehört dazu.
- **Der Skill Creator** als Weg, plus einmal von Hand — beides zeigen.

## Drei Dinge zum Drehen

**Der Ton bleibt der von Startklar** — geteilter Bildschirm, kein Schnitt-Feuerwerk,
keine Musik. Sie soll mitklicken können.

**Jedes „Zeigen" ist echt.** Kein nachgebautes Beispiel. Wenn beim Aufnehmen etwas
schiefgeht, bleibt es drin und wird kommentiert — das ist genau das, was die acht
Gratis-Anleitungen nicht haben.

**Zwei Lektionen sind das Geld wert:** 7.2 (leere gegen gefüllte Wissensdatei) und
10.5 (die echte Woche). Wenn nur zwei Lektionen richtig gut werden, dann diese beiden.

# 🗺️ Funnel-Landkarte — Mum Life Balance

> **Stand:** 2026-06-12 · Aus Live-Audit der 28 AC-Automationen + Julia-Trost-Methodik (Funnel-System + Produkttreppe) + `active-funnels.json`.
> **Architektur-Entscheidung (Patricia, 2026-06-12):** **Themen-Treppen ab dem Freebie** — 3 thematische Wege, die alle oben in die **MBA** münden. Verkauf der MBA läuft über ein **Webinar (Evergreen) bzw. das Bootcamp** als Brücke.
> **Kernziel:** Relevanz pro Person + alles führt zur MBA + niemand bekommt eine Mail-Sequenz doppelt.

---

## 1. Das Grundprinzip

Drei Dinge sauber getrennt halten:

- **Auslieferung** (das „Hier ist dein Freebie") → individuell pro Produkt, **kurz** (1–2 Mails).
- **Nurture** (Vertrauen + Aufstieg) → **eine pro Thema** (3 statt 1), zeigt Richtung des passenden grossen Kurses.
- **MBA-Verkauf** → passiert **nicht** per E-Mail, sondern über ein **Webinar / Bootcamp** (Verkaufsbühne). Alle Themen-Treppen münden dort.

```
3 THEMEN-WELTEN                       MID-TICKET (333)        TOP (Bundle)
──────────────                       ─────────────────        ────────────
🟢 Sichtbarkeit/Instagram  ─┐
   (Bio-Check, Starterguide,│─► Instagram-Kundenmaschine ─┐
    Story-Challenge)        │                             │
                            │                             │
🟡 Zeit/Struktur (Mama-CEO)─┼─► Mama-CEO ─────────────────┼─►  🎥 WEBINAR ─► 🎓 MBA
   (noch kein Freebie!)     │                             │    (Evergreen      (997/
                            │                             │     + Bootcamp)     1347)
🟣 Digitale Produktwelt  ───┘─► Digitale Produktwelt ─────┘
   (Lead-Challenge, Businessfahrplan)

   🔵 Von 0 auf echt = Foundation (theme-neutral) → routet via Quiz/Nurture ins Thema
```

**Wichtig — kein 3-fach-Angebot:** Jede Person sieht nur **ihre** Treppe, also genau **einen** 333-Kurs + die MBA als „alles zusammen". Keine Qual der Wahl.

## 3. SOLL-Architektur: die 3 Themen-Treppen → MBA

Jede Treppe gleich aufgebaut, nur Inhalt + Zielkurs unterscheiden sich:

```
THEMEN-FREEBIE
   │  Asset liefern (1-2 Mails) + Tag stufe:lead + Tag thema:<x>
   ▼
🟢/🟡/🟣 THEMEN-NURTURE (pro Thema 1×, 5-6 Mails)
   │  baut Vertrauen, pitcht Minikurs 39 → grosser Kurs 333 des Themas
   ▼
🎥 WEBINAR / BOOTCAMP  (verkauft die MBA — die Brücke zum grossen Ja)
   │
   ├─ kauft MBA ✅  → Tag kunde-mba → raus aus allem
   └─ kauft nicht  → bleibt warm, nächster Live-Launch holt sie ab
```

**Was ist geteilt, was thematisch?**

| Baustein | geteilt (1×) | pro Thema (3×) |
|---|---|---|
| Auslieferungs-Automationen | — | je Freebie |
| Lead-Nurture | — | ✅ 3 (Inhalt + Zielkurs verschieden) |
| Webinar / Bootcamp | ✅ verkauft MBA | — |
| Angebots-/Cart-Sequenz nach Webinar | ✅ | — |
| Anti-Dopplungs-System | ✅ | — |

→ Der Mehraufwand gegenüber „ein Funnel" ist also **nur die 3 Nurture-Inhalte** — Webinar, Cart und Technik baust du **einmal**.

### 🎥 Die Webinar-Brücke (Evergreen + Bootcamp)
- **Bootcamp** (live, paar Mal/Jahr) = grosser Push, ganze Liste.
- **Evergreen-Webinar** = stiller Motor dazwischen: einmal aufnehmen → Anmelde-Seite → sofort-Replay → 3-Tage-Angebotsfenster. Fängt Leute ab, die zwischen den Live-Launches „reif" werden. Inhalt aus KI-Webinar (20.5.) + Mama-CEO-Mails recycelbar.

## 4. ❤️ Anti-Dopplungs-System + Themen-Routing

### Die Tags
| Tag | Wann | Zweck |
|---|---|---|
| **`stufe:…`** (`lead`/`kunde-mini`/`kunde-signature`/`kunde-mba`) | bei jedem Aufstieg | höchste erreichte Stufe |
| **`thema:…`** (`instagram`/`mama-ceo`/`produktwelt`) | beim Einstieg (welches Freebie) | steuert, welche Themen-Nurture läuft |
| **`nurture:lead-fertig`** | Ende der Lead-Nurture | „Sequenz schon durchlaufen" |
| **`nurture:aktiv`** | Start einer Nurture, Ende entfernt | Ampel: keine zwei gleichzeitig |

### Die Regeln (verhindern Doppel-Mails — dein Kernanliegen)
1. **Lead-Nurture nur 1×:** erster Schritt „wenn `nurture:lead-fertig` ODER `kunde` → beenden". Holt jemand ein 2. Freebie → nur Asset, keine Mail-Sequenz nochmal.
2. **Ampel `nurture:aktiv`:** zweite Übergabe wartet, bis die erste fertig ist. Kein Stakkato.
3. **Goal „kauft":** wer kauft, fliegt sofort aus den Lead-Mails → Kunden-Nurture.

### 🧭 Quiz als Themen-Router
Der **Potenzial-Test (52)** ist ideal, um Leute mit unklarem Thema einzusortieren: je nach Ergebnis Tag `thema:instagram` / `mama-ceo` / `produktwelt` setzen → richtige Treppe.

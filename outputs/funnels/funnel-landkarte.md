## 1. Das Grundprinzip (deine Vision, sauber gebaut)

Du hast völlig recht mit deiner Idee: **nicht jeder Einstieg braucht seinen eigenen langen Funnel.** Der Trick ist, zwei Dinge zu trennen, die heute vermischt sind:

- **Auslieferung** (das „Hier ist dein Freebie/Kurs") → individuell pro Produkt, aber **kurz** (1–2 Mails). Das *muss* einzeln sein, weil jedes Produkt ein anderes PDF / einen anderen Link liefert.
- **Nurture** (die Vertrauens- und Aufstiegs-Sequenz Richtung MBA) → **eine gemeinsame Sequenz pro Treppen-Stufe**, die alle Einstiege teilen.

Bildlich: viele **Speichen** (Auslieferung) laufen in **wenige Naben** (Sammel-Nurture). So musst du Mails nur einmal pflegen, und niemand bekommt sie doppelt.

```
  FREEBIES (Speichen)              SAMMEL-NURTURE (Nabe)        ZIEL
  ─────────────────                ─────────────────────        ────
  Bio-Check ┐
  Lead-Challenge ┤
  Von 0 auf echt ┤──► [Asset liefern] ──► 🟢 LEAD-NURTURE ──┐
  Potenzial-Test ┤    (1-2 Mails je)      (1× gemeinsam,     │
  Starterguide ┤                           Richtung Minikurs) │
  Story-Challenge ┘                                           │
                                                              ▼
  MINI/SIGNATURE-KÄUFER ──► [Willkommen] ──► 🔵 KUNDEN-NURTURE ──►  🎓 MBA
  (Finde dein Thema 39 ·                     (1× gemeinsam,        (Bundle
   Expertin 97 ·                              Aufstieg Richtung     997/1347)
   3 grosse Kurse 333)                        nächste Stufe)
```

## 4. ❤️ Das Anti-Dopplungs-System (dein Kernanliegen)

**Dein Szenario:** „Wenn jemand das eine 0€-Produkt geholt hat und dann das andere, soll er nicht nochmal alle Mails bekommen." → Genau das löst dieses 3-Tag-System.

### Drei Steuer-Tags

| Tag | Wann gesetzt | Zweck |
|---|---|---|
| **`stufe:…`** (`lead` / `kunde-mini` / `kunde-signature` / `kunde-mba`) | bei jedem Auf­stieg | Markiert die **höchste erreichte Stufe**. Jede hat immer nur ihre höchste. |
| **`nurture:lead-fertig`** | am **Ende** der Lead-Nurture | „Hat die Lead-Sequenz schon durchlaufen." |
| **`nurture:aktiv`** | beim **Start** einer Nurture, entfernt am Ende | Ampel: läuft gerade eine Sequenz? |

### Die zwei Regeln, die das Doppeln verhindern

**Regel 1 — Lead-Nurture nur EINMAL im Leben:**
Erster Schritt der Lead-Nurture:
> „Wenn Kontakt Tag `nurture:lead-fertig` ODER `kunde` (egal welcher) hat → **Automation sofort beenden**."

→ Holt jemand ein 2., 3. Freebie, bekommt sie das **Asset** (aus der kurzen Auslieferung), aber **nie wieder die 6 Nurture-Mails.** Genau dein Wunsch.

**Regel 2 — nie zwei Sequenzen gleichzeitig (Ampel):**
Erster Schritt jeder Nurture:
> „Warte, bis Kontakt **nicht** Tag `nurture:aktiv` hat" → dann Tag setzen → Sequenz → am Ende Tag entfernen.

→ Lädt jemand am selben Tag zwei Freebies, läuft die zweite Übergabe **wartet**, bis die erste fertig ist. Kein Mail-Stakkato.

**Regel 3 — Käufer fliegen aus Lead-Mails raus (Goal):**
Jede Lead-Nurture bekommt ein **Goal** „Tag `kunde` erreicht → Automation beenden". Wer kauft, hört sofort auf, Lead-Mails zu kriegen, und wechselt in die Kunden-Nurture.

> 💡 AC kann diesen Flow-Umbau **nicht per API** — du klickst die Bedingungen einmal im Automation-Editor rein (Anleitung in Schritt 5). Danach läuft alles automatisch, und ich kann jederzeit Kontakte/Tags/Mails per API verwalten.

## 5. Entknäuelungs-Plan (Schritt für Schritt)

**Reihenfolge bewusst: erst sichern, dann aufräumen, dann das Anti-Dopplungs-System.**

1. **Sichern (5 Min):** Die 3 Sammel-Nurture-Automationen, die du behalten willst, je einmal als **Share-Link exportieren** (AC: Automation → „…" → Share) — als Backup, bevor du etwas änderst.
2. **Doppelungen zusammenlegen (je entscheiden welche behalten):**
   - Bio-Check: **58** behalten, **59** archivieren (Inhalt vorher rüberziehen).
   - Finde dein Thema: **53** behalten, **46** archivieren.
   - IG-Kundenmaschine: **54** behalten, **44** archivieren.
   - Digitale Produktwelt: **eine** von 48/51/56 behalten, zwei archivieren.
3. **Altbestände prüfen:** 15, 37, 42, 43 — noch aktuell? Sonst auf „inaktiv".
4. **Sammel-Nurtures bauen:** 1× 🟢 Lead-Nurture, 1× 🔵 Kunden-Nurture, 1× 🌿 doTERRA-Nurture. Die Auslieferungs-Automationen kürzen auf „Asset + Tag `stufe:lead` + ab in die Lead-Nurture".
5. **Anti-Dopplungs-Regeln einbauen** (Regel 1–3 aus Abschnitt 4) in jede Nurture.
6. **Testen:** Test-Kontakt anlegen, nacheinander 2 Freebies auslösen → prüfen, dass nur 1× Nurture läuft. (Das mache **ich** per API: `create_contact` + Tags setzen + `get_contact` zum Kontrollieren.)

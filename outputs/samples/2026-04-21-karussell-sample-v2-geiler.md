# SAMPLE 3-V2 — Karussell GEILER gestaltet

**Was ist anders als V1?** Design-Drama aus `karussell-framework.md` → „EINE Hero-Phrase pro Folie", typografische Hierarchie, Kontrast-Folien (Problem schwarz / Lösung hell), grosse Zahlen als Design-Element, Mix aus Text- und Visual-Folien.

**Hook** (unverändert): „5 Sätze, nach denen deine Freundinnen aufhören zu kaufen"
**Folien-Anzahl:** 10 (1 mehr als V1 für Visual-Break)
**Profil:** Mentoring
**Pillar:** M4 (IG-Strategie) + M1 (Positionierung)
**Keyword:** `SICHTBAR`

---

## Folie 1 — COVER (Hero-Typ)

**Hintergrund:** Creme (#f1ecdd)
**Layout:**
```
[OBEN: kleines Micro-Detail]
„Fürs Feed gespeichert →"   ← Ebene 3, Gray #8a8a8a, 20pt

[MITTE: Hero-Statement, zentral]
          5 Sätze,          ← Ebene 1, Serif Bold, 88pt, Petrol
    nach denen deine        ← Ebene 1, Serif Bold, 64pt, Petrol
    Freundinnen             ← Ebene 1, Serif Bold, 64pt, Petrol  
    aufhören zu kaufen.     ← Ebene 1, Serif Bold, 64pt, Dunkelblau (Kontrast-Farbe auf letztem Wort)

[UNTEN: Swipe-Indikator]
Nr. 4 sagst du fast täglich.   ← Ebene 2, Sans-Serif, 28pt, Gray #5a5a5a
                    →
```

**Design-Twist:**
- „aufhören zu kaufen" ist in Dunkelblau — erzeugt visuellen Sprung
- Unter „Sätze" eine **handgeschriebene Unterstreichung** in Orange (#dc822e) — Procreate-Style, wie mit Filzstift gezogen
- Viel Weissraum oben/unten

## Folie 2 — STORY-EINSTIEG (Visual-Typ)

**Hintergrund:** Creme, mit kleinem Portrait-Foto von Patricia rechts (aus `Shootingbilder`)
**Layout:**
```
[LINKS: Text 60% Breite]

  Du postest.
  Du schreibst.              ← Serif, 42pt, kurze Sätze untereinander
  Du fragst nach.

  Und trotzdem:
  Stille.                    ← ganz gross, 72pt, Dunkelblau

[RECHTS: kleines Patricia-Foto 35% Breite, warm lächelnd]
```

**Design-Twist:**
- Die 3 Sätze „Du postest / Du schreibst / Du fragst" sind kurz — Rhythmus
- „Stille." bricht das Muster — grösser, einzeln, mit Punkt als Endpunkt
- Patricia-Foto gibt Gesicht zur Geschichte

## Folie 3 — PROBLEM-FOLIE (Dunkel-Typ)

**Hintergrund:** Dunkelblau (#29556d) — **hier bricht das Design absichtlich!**
**Layout:**
```
[ZENTRIERT]

     Das liegt an
     einem von
     5 Sätzen.              ← Serif Bold, 72pt, CREME (#f1ecdd)

     Du sagst sie täglich.   ← Sans-Serif, 30pt, Creme-abgedunkelt

     — ohne zu merken, 
     dass sie killen.        ← Sans-Serif Italic, 26pt, Orange (#dc822e)
```

**Design-Twist:**
- Der Farbwechsel Creme→Dunkel ist der optische Reset. User scrollt, sieht dunkel = „oh, jetzt wird's ernst"
- Das Wort „killen" in Orange hebt sich ab — signalisiert Gefahr
- Kein Bild, pures Text-Drama

## Folie 4 — SATZ NR. 1 (Zahlen-Typ)

**Hintergrund:** Creme
**Layout:**
```
[OBEN, RIESIG, halb-transparent, Petrol]
              1             ← Zahl in 400pt, Outline-Stil (nicht gefüllt), Petrol 30% Transparenz

[MITTE, VOR der Zahl]
  „Ich hab da was Tolles,   ← Serif Italic, 42pt, Dunkelblau
   das musst du dir 
   unbedingt mal ansehen."

[UNTEN, klein]
Warum das killt:            ← Sans-Serif, 24pt, Gray
„Tolles" ist leer. 
„Unbedingt" ist Druck. 
Sie liest: VERKAUF.          ← „VERKAUF" in Orange, fett
```

**Design-Twist:**
- Die „1" dominiert die Folie als Design-Element, Text steht vor/in ihr
- Das Zitat ist in Anführungszeichen, Italic — wie gesprochen
- „VERKAUF" in Orange + Caps — Highlight-Effekt

## Folie 5 — SATZ NR. 2 + VISUAL-BREAK

**Hintergrund:** Creme
**Layout:**
```
[OBEN LINKS, GROSS:]
             2

[MITTE, Anführungszeichen als Design-Element:]
❝                           ← Massiv gross (180pt), halb-transparent Petrol, hinter dem Text

  Das hat SO vielen schon    ← Serif, 40pt, Dunkelblau (vor den Anführungszeichen)
  geholfen, probier es 
  einfach mal.

                        ❞   ← Abschluss-Anführung unten rechts, symmetrisch

[UNTEN]
„SO vielen" = unspezifisch.  ← Sans, 22pt, Gray
„Einfach mal" = bagatellisieren.
Sie fühlt sich wie Nummer 74.  ← „Nummer 74" unterstrichen Orange
```

**Design-Twist:**
- Riesige Anführungszeichen ❝ ❞ als Gestaltungs-Element (nicht nur Satzzeichen)
- „Nummer 74" handgeschrieben unterstrichen
- Kein Foto hier — pure Typografie

## Folie 7 — SATZ NR. 4 (die CLIFFHANGER-SPITZE)

**Hintergrund:** Dunkelblau — wieder Kontrast-Wechsel!
**Layout:**
```
[DIE ZAHL IST DAS DESIGN — FÜLLT 70% DER FOLIE:]

         4               ← Serif, 480pt, CREME (volles Gewicht, Outline + etwas Füllung)

[ÜBER der 4, zentriert:]
„Wie geht's dir?           ← Serif Italic, 38pt, Creme
 Ach übrigens..."

[UNTER der 4:]
Der „Ach übrigens"-Move.    ← Orange, 26pt
Sie hat das 12x erlebt.
```

**Design-Twist:**
- Die „4" ist fast so gross wie die Folie — visuell anders als 1, 2, 3
- Das signalisiert: DAS IST DIE WICHTIGSTE NUMMER
- Wieder Dunkelblau für Kontrast
- „Ach übrigens" in Italic — als Zitat erkennbar

## Folie 8 — SATZ NR. 5

**Hintergrund:** Creme
**Layout:**
```
             5

  „Ich bin grad in diesem      ← Serif, 42pt, Dunkelblau
   Programm und..."

[HANDGESCHRIEBEN-MARKIERUNG, wirkt wie Filzstift:]
Sie interessiert sich nicht   ← 30pt, Dunkelblau
für dein _Programm_.          ← „Programm" durchgestrichen!
Sie interessiert sich für 
ihre _Probleme_.              ← „Probleme" unterstrichen Orange
```

**Design-Twist:**
- Durchgestrichen/unterstrichen als visuelle Kontrast-Mechanik
- Das Wort „Programm" durchgestrichen = „nein, das nicht" — das Wort „Probleme" unterstrichen = „ja, das!"
- Extrem konkret, lesbar in 2 Sekunden

[UNTEN, klein]

**Design-Twist:**
- „zeig ihr, dass du IHR Problem verstehst" = Kern-Message in grösster Schrift
- „IHR" ist CAPS, optisch hervorgehoben
- Petrol-Streifen oben = Design-Konsistenz/Signature

## Zusammenfassung der Design-Moves (Checkliste für Canva)

- ✅ **Kontrast-Folien**: Hell/Dunkel/Hell/Dunkel — bricht Monotonie
- ✅ **Zahlen als Design-Hero** auf Fehler-Folien (1, 2, 3, 4, 5 — Nr. 4 grösser als Rest)
- ✅ **Anführungszeichen ❝ ❞** als visuelles Element auf Folie 5
- ✅ **Highlight-Box** (Orange) um Kernwort auf Folie 6 + 10 (Keyword)
- ✅ **Handgeschriebene Unterstreichung/Durchstreichung** auf Folie 1, 5, 8, 9
- ✅ **Serif Bold für Hero**, Sans Regular für Subtext → klare Hierarchie
- ✅ **EIN Foto** (Folie 2) — nicht 9 Folien pur Text
- ✅ **Weissraum** min. 20% pro Folie
- ✅ **Farb-Rotation**: Creme → Creme → **DUNKELBLAU** → Creme → Creme → Creme → **DUNKELBLAU** → Creme → Creme+Akzent → **PETROL**

## Was mit diesem Design-Ansatz besser wird

1. **Scroll-Stop:** Cover mit Serif-Bold in 88pt + handgeschriebene Unterstreichung = Feed-Differenz
2. **Swipe-Rate:** Kontrast-Wechsel Hell/Dunkel zwingt den Blick weiterzuscrollen
3. **Saves:** Folie 10 macht Save-CTA explizit mit Icon — 2026 ist das der wichtigste Algo-Trigger für Karussells
4. **Teilbarkeit:** Einzelne Folien (Folie 7 — die „4") funktionieren auch als Story-Teaser
5. **Wiedererkennung:** Petrol-Streifen + Orange-Highlight + Creme/Dunkelblau-Palette = dein Look

## Canva-Umsetzungs-Tipp

- Erstelle 1x das Template mit allen 10 Folien
- Dupliziere für zukünftige „5er-Listen"-Karussells — nur Texte austauschen
- Spare dir Stunden pro Karussell nach diesem Setup

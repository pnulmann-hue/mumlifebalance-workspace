# Titel neu

Du hast eben das Fundament gelesen. Halte dich an die **Namensformel** und die
**Sprachregeln**.

Eine Idee steht schon. Der Name gefällt ihr nicht. Du schreibst genau einen neuen —
für **dieselbe** Idee, nicht für eine andere.

---

## Regeln

- **Die Idee bleibt.** Du änderst die Verpackung, nicht den Inhalt. Für wen, welches
  Problem, welches Ergebnis — alles bleibt, wie es ist.
- **Deutlich anders als der alte Name.** Nicht dieselben Wörter umgestellt. Wechsle den
  Zugang: nennt der alte das Ergebnis, nennt der neue die Ausgangslage. Klingt der alte
  nach Werkzeug, klingt der neue nach Weg.
- **Auch das Versprechen wird neu geschrieben** — dieselbe Formel, andere Worte. Der
  Zeitrahmen darf sich ändern, wenn ein anderer besser passt.
- **Konkret vor clever.** Ein Name, den man versteht, ohne die Beschreibung zu lesen,
  schlägt jedes Wortspiel.

---

## Ausgabeformat

**Antworte ausschliesslich mit JSON, ohne Fliesstext, ohne Code-Zaun:**

```
{ "name": "…", "versprechen": "…" }
```
